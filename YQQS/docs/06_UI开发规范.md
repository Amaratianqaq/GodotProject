# 06 · UI 开发规范

> 本项目 UI 走的是**代码构建**路线：`.tscn` 里只有一个挂脚本的根节点，
> 所有子控件在 `_ready()` 里用 `UIKit` 创建。
> 本文说明为什么这样做、怎么做、以及新增界面的标准流程。

---

## 1. 为什么用代码建 UI

| 理由 | 说明 |
|---|---|
| **数据驱动** | 背包 24 格、仓库 60 格、技能树 22 个节点 —— 数量都随配置变化，手写 `.tscn` 每次改配置都要重排 |
| **一致性** | 所有面板走同一套 `UIKit` 样式工厂，不会出现「这个面板边框是 2px 那个是 1px」 |
| **可 diff** | 布局逻辑是文本代码，code review 能看懂；`.tscn` 的 diff 基本不可读 |
| **可靠** | 手写 `.tscn` 的 `load_steps` 计数、`ExtResource` id、锚点很容易写错，且错误往往在运行时才炸 |

**代价**：不能在编辑器里可视化拖拽。这是本项目**有意识接受**的取舍 ——
因为界面数量少（5 个）且高度模板化。

> 什么时候该改回 `.tscn`：如果某个界面变成「一次性、布局独特、几乎不复用」的
> （例如复杂的商店页面），用 `.tscn` 手摆会更划算。届时把它作为例外写进本文档。

## 2. UIKit（`scripts/ui/ui_kit.gd`）

### 2.1 语义色常量
**禁止**在界面里写颜色字面量，一律用这些：

| 常量 | 用途 |
|---|---|
| `COL_BG` / `COL_PANEL` / `COL_PANEL_DARK` | 背景层 |
| `COL_BORDER` / `COL_BORDER_LIGHT` | 边框 |
| `COL_TEXT` / `COL_TEXT_DIM` | 正文 / 次要文字 |
| `COL_GOLD` | 金币、强调 |
| `COL_HP` / `COL_ARMOR` / `COL_MP` / `COL_XP` | 血 / 甲 / 蓝 / 经验 |
| `COL_DANGER` / `COL_OK` | 失败 / 成功提示 |
| `COL_SLOT_BG` / `COL_SLOT_HOVER` | 格子背景 |

品质色统一走 `GameEnums.rarity_color(rarity)`（白/绿/蓝/橙）。

### 2.2 尺寸规范（480×270 逻辑分辨率）
| 常量 | 值 | 说明 |
|---|---|---|
| `FS_TINY` | 9 | 次要说明、格子数字 |
| `FS_SMALL` | 11 | 正文 |
| `FS_NORMAL` | 13 | 按钮 |
| `FS_LARGE` | 18 | 面板标题 |
| `FS_TITLE` | 24 | 大标题 |
| `SLOT_SIZE` | 26 | 物品格子 |
| `PADDING` | 6 | 面板内边距 |

### 2.3 控件工厂
| 方法 | 返回 | 用途 |
|---|---|---|
| `label(text, size, color, align)` | Label | 带描边的文字（保证任何底色上都可读） |
| `rich_label(text, size)` | RichTextLabel | BBCode（物品 tooltip、技能说明） |
| `button(text, size)` | Button | 已套好 4 态样式（normal/hover/pressed/disabled） |
| `panel(title)` | PanelContainer | 木质九宫格容器 |
| `panel_stylebox(bg, border, width)` | StyleBoxFlat | 深色面板样式 |
| `wood_stylebox()` | StyleBoxTexture | 用 `ui_panel.png` 的木质边框 |
| `slot_stylebox(rarity, hovered)` | StyleBoxFlat | 格子样式（品质色描边） |
| `dimmer(alpha)` | ColorRect | 模态面板的全屏遮罩 |
| `vbox(sep)` / `hbox(sep)` / `spacer()` | 容器 | 布局 |
| `spacer(size)` | Control | 撑开剩余空间 |
| `item_tooltip(stack)` | String | 物品完整 BBCode tooltip |

## 3. 中文字体（关键，别踩坑）

Godot 内置字体**没有 CJK 字形**，直接用中文会显示成空白/方块。

解决方案在 `SceneRouter._setup_font()`：使用 **`SystemFont`** + `ThemeDB.fallback_font`。

```gdscript
var f := SystemFont.new()
f.font_names = PackedStringArray([
    "Microsoft YaHei UI", "Microsoft YaHei", "微软雅黑",
    "SimHei", "黑体", "Noto Sans CJK SC", "Source Han Sans SC", "sans-serif",
])
f.antialiasing = TextServer.FONT_ANTIALIASING_GRAY
f.subpixel_positioning = TextServer.SUBPIXEL_POSITIONING_DISABLED
ThemeDB.fallback_font = f
ThemeDB.fallback_font_size = 12
```

**好处**：不需要把字体文件打包进仓库（省几 MB 且无授权问题），跨机器自动回退。

**约定**：
- **不要**在别处再设置字体，一律靠 `ThemeDB.fallback_font`。
- 界面上只用 `add_theme_font_size_override("font_size", UIKit.FS_XXX)` 调字号。
- 如果要换成像素 CJK 字体（例如 Zpix），只需把 `assets/fonts/xxx.ttf` 放进项目，
  在 `_setup_font()` 里优先 `load()` 它，其余代码不动。

### 3.1 为什么拉伸模式必须是 `canvas_items`
见 [01 号文档 §3.4](01_框架总览.md)。
一句话：`viewport` 模式会把中文按 480×270 渲染再放大 → 糊；
`canvas_items` 模式精灵仍像素完美、文字按放大后的分辨率渲染 → 清晰。

## 4. 布局约定

- 逻辑分辨率固定 **480×270**，`stretch/aspect = keep` + `scale_mode = integer`，
  所以 Control 坐标空间**恒定**。
- HUD 用 `_place(ctrl, x, y, w, h)` **固定像素坐标**（不做 anchor 计算），
  这样在任何窗口尺寸下观感一致，也容易对齐。
- 模态面板：`dimmer()` 铺满 → 内容用 `position` 居中（例如 `Vector2(240 - w/2, 135 - h/2)`）。
- 面板根节点必须 `set_anchors_and_offsets_preset(PRESET_FULL_RECT)`
  （`SceneRouter.open_panel` 也会兜底设置）。

## 5. 面板的注册、打开、暂停

### 5.1 注册
在 `SceneRouter.PANEL_SCENES` 里登记：

```gdscript
const PANEL_SCENES := {
    &"inventory":  "res://scenes/ui/InventoryPanel.tscn",
    &"warehouse":  "res://scenes/ui/WarehousePanel.tscn",
    &"skill_tree": "res://scenes/ui/SkillTreePanel.tscn",
    &"pause":      "res://scenes/ui/PauseMenu.tscn",
}
const EXCLUSIVE_PANELS := [&"inventory", &"warehouse", &"skill_tree", &"pause"]
```

### 5.2 打开
**唯一入口**：`EventBus.ui_open_requested.emit(&"inventory")`。
`SceneRouter` 订阅它 → `toggle_panel()`（已开则关）。

发起方：
- `Player._handle_actions` —— 键盘快捷键
- `PanelAltar._on_activated` —— 大厅设施
- 任意按钮的 `pressed` 信号

### 5.3 互斥与暂停
- `EXCLUSIVE_PANELS` 里的面板**互斥**：打开一个会自动关掉其它。
- 打开互斥面板 → `SceneRouter.set_paused(true)`；
  全部关闭 → `set_paused(false)`。
- 面板挂在 `SceneRouter` 的 `CanvasLayer(50)` 下，而 `SceneRouter.process_mode = ALWAYS`，
  所以**面板在暂停时仍然可以交互**。
- 关卡内的物理与 AI 会被 `get_tree().paused` 冻结（它们没有设 ALWAYS）。

### 5.4 关闭
- 按钮：`SceneRouter.close_panel(&"inventory")`
- 快捷键：面板自己实现 `_unhandled_input`，监听对应的 action 与 `pause`：
  ```gdscript
  func _unhandled_input(event: InputEvent) -> void:
      if event.is_action_pressed("inventory") or event.is_action_pressed("pause"):
          SceneRouter.close_panel(&"inventory")
          get_viewport().set_input_as_handled()
  ```

## 6. 数据交互约定

### 6.1 面板不持有数据
面板**只做展示 + 发起操作**，所有变更走：

| 操作 | 调用的 API |
|---|---|
| 背包增删改 | `GameState.inventory.*` |
| 仓库存取 | `WarehouseService.*` |
| 装备武器 | `Player.equip_weapon(data, slot)` |
| 使用消耗品 | `Player.use_consumable(index)` |
| 技能加点 | `SkillTreeService.unlock(id)` |

**禁止**在面板里直接改 `inventory.slots` / `GameState.gold`。

### 6.2 刷新靠信号，不靠轮询
```gdscript
func _ready() -> void:
    EventBus.inventory_changed.connect(_refresh)
    EventBus.weapon_equipped.connect(func(_d, _s): _refresh())
    _refresh()                       # 打开时主动刷一次
```
HUD 是个例外：它的**条状数值**每帧读（血条要平滑），
但**事件型信息**（提示条、BOSS 出现）仍然走信号。

### 6.3 格子交互约定（背包与仓库统一）
| 操作 | 背包 | 仓库 |
|---|---|---|
| 左键 | 装备（武器）/ 使用（药水） | 整叠取出 |
| 右键 | 丢弃 1 个 | 取出 1 个 |
| Shift + 左键 | （同左键） | 同类全搬 |

`ItemSlot.Source` 枚举区分格子来源（`NONE / INVENTORY / WAREHOUSE`），
`slot_clicked(index, source, mouse_button)` 一处分发。

## 7. HUD 结构（`scripts/ui/hud.gd`）

```
左上：等级 + 生命条 + 护甲条 + 能量条 + 经验条
右上：金币、楼层/击杀/种子
中上：BOSS 血条（boss_spawned 后显示）
左下：两个武器槽 + 武器名 + 弹药 + 冷却/装填条
右下：技能图标 + 冷却遮罩 + 「必暴就绪」
底部中央：交互提示 [E] xxx、提示条队列（最多 4 条，2.4s 淡出）
```

**性能约定**：每帧刷新的只有 `_update_weapon_live / _update_skill_live /
_update_boss_live / _update_prompt / _update_info / _update_toasts`，
它们只读状态、不分配节点（提示条除外）。

## 8. 新增一个面板的标准流程

以「图鉴（Codex）」为例：

1. **脚本** `scripts/ui/codex_panel.gd`
   ```gdscript
   class_name CodexPanel
   extends Control

   func _ready() -> void:
       set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)
       mouse_filter = Control.MOUSE_FILTER_STOP
       add_child(UIKit.dimmer())
       var box := PanelContainer.new()
       box.add_theme_stylebox_override("panel", UIKit.wood_stylebox())
       box.position = Vector2(240 - 200, 135 - 110)
       box.custom_minimum_size = Vector2(400, 220)
       add_child(box)
       var v := UIKit.vbox(4)
       box.add_child(v)
       v.add_child(UIKit.label("图鉴", UIKit.FS_LARGE, UIKit.COL_GOLD,
           HORIZONTAL_ALIGNMENT_CENTER))
       # …用 ConfigDB.all_weapons() / all_enemies() 填内容
       var b := UIKit.button("关闭 (L)", UIKit.FS_SMALL)
       b.pressed.connect(func() -> void: SceneRouter.close_panel(&"codex"))
       v.add_child(b)

   func _unhandled_input(event: InputEvent) -> void:
       if event.is_action_pressed("pause"):
           SceneRouter.close_panel(&"codex")
           get_viewport().set_input_as_handled()
   ```
2. **场景** `scenes/ui/CodexPanel.tscn`（只有一个 Control 根节点 + 挂脚本）：
   ```
   [gd_scene load_steps=2 format=3]
   [ext_resource type="Script" path="res://scripts/ui/codex_panel.gd" id="1_codex"]
   [node name="CodexPanel" type="Control"]
   anchors_preset = 15
   anchor_right = 1.0
   anchor_bottom = 1.0
   script = ExtResource("1_codex")
   ```
3. **登记** `SceneRouter.PANEL_SCENES[&"codex"]`，若要互斥再加进 `EXCLUSIVE_PANELS`。
4. **输入映射** 在 `tools/setup_project.gd::KEY_ACTIONS` 加 `"codex": [[76], []]`（L 键），
   重跑 `setup_project.gd` + `--import`。
5. **打开入口**：`Player._handle_actions` 里
   `if Input.is_action_just_pressed("codex"): EventBus.ui_open_requested.emit(&"codex")`；
   或者在大厅放一个 `PanelAltar`（`panel_id = &"codex"`）。
6. **验证**：跑 `Validation.tscn`（会自动加载新场景）+ `Screenshot.tscn --panel=codex`。

## 9. 已知缺口（第二阶段要做）

| 缺口 | 说明 |
|---|---|
| 无拖拽 | 背包/仓库目前是点击搬运，没有鼠标拖拽物品 |
| 无滚动 | 技能树画布固定尺寸；面板若超出 480×270 需要加 `ScrollContainer` |
| 无 tooltip 主题 | 目前用 Godot 默认 tooltip（`Control.tooltip_text`），风格与自绘面板不完全统一 |
| BOSS 血条不显示护甲段 | `boss_bar` 只接了 HP |
| 无按键重绑定界面 | 输入映射在 `setup_project.gd` 里写死 |
| HUD 提示条位置固定 | 没有做「同类提示合并」 |
