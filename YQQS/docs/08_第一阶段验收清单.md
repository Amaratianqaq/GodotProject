## 4. 已知差距（**如实列出**）

### 4.1 完全没有的东西

| 项 | 状态 | 说明 |
|---|---|---|
| **音频资源** | ❌ 无 | `assets/audio/` 为空。所有 `sfx_*` 路径已经在 `.tres` 里配好，`AudioManager` 对不存在的文件**静默跳过**。丢入 `.wav/.ogg` 即自动生效，无需改代码 |
| **存档缩略图 / 多角色槽位** | ❌ 无 | 只有 3 个线性槽位 |
| **手柄支持** | ❌ 无 | `setup_project.gd` 里只映射了键鼠 |
| **设置界面** | ❌ 无 | 音量 API 存在（`AudioManager.set_*_volume`）但没有 UI |
| **商店 / NPC / 合成** | ❌ 无 | 第二阶段 |
| **加速/减速效果、异常状态** | ❌ 无 | `DamageType` 里有 POISON/FIRE 但未接入逻辑 |

### 4.2 有但不完整

| 项 | 现状 | 缺什么 |
|---|---|---|
| **12 把品质武器** | 只有贴图 + 走默认实现（能开火、有伤害、有弹道），**没有专属机制** | 这正是需求里写的「代码实现后续添加」。做的时候按 [07 号文档](07_樱花霰弹枪实现说明.md) §5 的模板 |
| **相机屏幕震动** | `EventBus.screen_shake_requested` 有广播，但**没有消费者** | 需要一个 `CameraShake` 组件挂到 `Player/Camera2D` 上 |
| **技能树 UI 滚动** | 画布 440×172 固定，22 个节点刚好放下 | 再加分支就需要 `ScrollContainer` |
| **仓库/背包拖拽** | 只有点击搬运 | 鼠标拖拽 |
| **BOSS 血条** | 只显示生命，不显示护甲段 | `boss_bar` 增加护甲层 |
| **提示条** | 固定位置，最多 4 条 | 同类合并、优先级 |
| **敌人寻路** | 直线追击，不会绕障碍 | 走廊里会卡在树上。第二阶段上 `NavigationRegion2D` |
| **房间门** | 只是视觉上的开口，没有门扇/开关 | 战斗锁门（原作有） |
| **多层关卡** | `RunManager.next_floor()` 已实现但**没有第二层内容** | 需要更多地图配置 |
| **染色变体** | `goblin_chief` 复用 `goblin` 贴图 + `sprite_modulate` | 长期应出独立贴图 |

### 4.3 有意的简化（不是缺陷）

| 简化 | 理由 |
|---|---|
| 2D 俯视代替真 3D 等距 | 像素风下真 3D 难以保证像素对齐；`y_sort + z_height` 已能达到「前遮后、跳起离地」的观感 |
| UI 代码构建而非 `.tscn` | 见 [06 号文档](06_UI开发规范.md) §1 |
| 12 把武器共用一个默认实现 | 需求明确写了「只有贴图，代码实现后续添加」 |
| 用系统字体而非打包 CJK 字体 | 免授权问题、省体积；换像素字体只需改 `SceneRouter._setup_font()` |
| 8 个敌人共用一个 `Enemy.tscn` | 数据驱动，避免为每只怪写一个场景/脚本 |
| 顿帧期间暂停 UI 动画 | `Engine.time_scale` 是全局的；这是顿帧的正常代价 |
